# 素读（sudu）——一款轻量级 Markdown 阅读器

素读是一个安静、轻量的中文 Markdown 阅读器。它不管理知识库，也不塞满插件；它把 Markdown 排好、让章节随手可达、把界面退到文字后面，同时保留一个渲染态原位编辑。

## 原位编辑

点右上角铅笔或按 Ctrl+E，页面不会切成整页源码。点击任意段落、标题、列表项、引用、代码块或表格行，只有这一块在原位变成编辑区，字体和排版保持阅读时的样子；Markdown 标记会在该块内隐藏。

改完按 Ctrl+S 保存整篇，勾号按钮效果相同。未保存时切换文件或关闭窗口会被拦下。

## 特性

### 单色代码

代码块保持等宽单色，不做语法着色。阅读器首先保证行宽、行高和可选中，颜色交给主题统一决定。

```rust
fn main() {
    println!("你好，素读");
}
```

### 段落和文本

正文统一使用系统无衬线字体（微软雅黑 UI）。行高、段距、正文宽度都可以在设置里调整。中英文混排时，基线与标点应当保持稳定。

### 大纲

左侧大纲只列出标题，按层级缩进，点击即可跳转。滚动时当前章节自动高亮，不显示文件树。

### 表格

| 项目 | 说明 |
| --- | --- |
| 主题 | 白、纸、夜、米黄 |
| 大纲 | Ctrl+B |
| 搜索 | Ctrl+F |

### 快捷键

- Ctrl+O：打开文件
- Ctrl+Shift+O：打开文件夹
- Ctrl+B：展开或收起大纲
- Ctrl+F：在本文中查找
- Ctrl+E：进入渲染态原位编辑
- Ctrl+S：保存并回到阅读
- Ctrl+T：切换主题
- Ctrl+= / Ctrl+-：调整字号
- Ctrl+R：重新读取文件
