# 素读样文：中文 Markdown 阅读测试

这是一份用来检查渲染、排版和交互的样文。它包含标题、段落、列表、表格、引用、代码块、链接和中文标点。

## 一、中文段落

阅读器的第一要务是让文字可读。中文正文的字号、行高、段距、行宽都要一起调。行高太紧会显得拥挤，太松会散掉；行宽太窄会频繁换行，太宽会让视线回扫困难。

这一段混排 English words, numbers 12345, and punctuation: , . ; : ? ! ( ) [ ]. 中西文的基线和字重应当协调，中文标点不应出现在行首（除少数情况），也不应紧贴行尾。

### 1.1 标点与断行

中文标点：，。；：？！「」『』（）【】《》。连续标点应当保持可读，不应被拆到两行。英文单词不应被从中间断开；长 URL 例外。

### 1.2 重复标题

重复标题用来测试锚点去重。

### 1.2 重复标题

## 三、表格

| 序号 | 参数名 | 详细说明 |
| ---: | --- | --- |
| 1 | font_size | 正文字号，单位像素，默认 17 |
| 2 | line_height | 行高倍数，默认 1.85 |
| 3 | content_width | 正文最大宽度，默认 760 |
| 4 | theme | 主题名称：白、纸、夜、米黄 |

## 四、引用

> 阅读器应当让文字自己说话，界面退到背景里。
>
> 第二段引用：留白不是空白，是让视线休息的地方。
